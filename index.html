ENGINEERING PRINCIPLES

How I Think & Build

Core beliefs guiding every technical decision, pull request, and system architecture.

01 // PLATFORM FIRST

Respect Device Constraints

Battery, frame budget, and memory limits are non-negotiable. Software must feel native, snappy, and light on system resources.

02 // ARCHITECTURE

Share Business Logic

Abstract domain logic cleanly across platforms using KMP & CMP, while leaving UI native where native performance matters most.

03 // AI SYSTEMS

AI as Executable Tools

LLMs are reasoning engines, not novelty chatbots. Integrate them into deterministic pipelines with explicit tool calling.

04 // OBSERVABILITY

Observability by Default

If you cannot inspect network requests or state transitions in real time, you cannot reliably scale or debug production apps.
